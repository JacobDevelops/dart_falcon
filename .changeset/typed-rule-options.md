Add typed rule options with kebab-case keys, rule-specific JSON schema completion, and load-time errors that identify the configuration path for invalid options. Loading rejects unsupported options, invalid values, mixed lists, and unknown member-order tokens instead of falling back to defaults. Whole-number numeric options and max-errors values such as `1.0` are accepted, out-of-range integers name their allowed range, and optional sections still accept null in both the loader and editor schema. Recognized legacy snake_case option keys remain accepted with deprecation warnings. `falcon migrate` normalizes keys, resolves collisions, moves known rules to their declared group and section, and uses structured error paths to report and repair invalid entries without deleting unrelated settings. It translates legacy flat settings and rule-level YAML exclusions, preserves legacy severity aliases and recursive exclusion patterns where possible, and warns how many formerly implicit rules need explicit enablement. It refuses ambiguous legacy exclusions and repairs that would erase a whole section, and preserves scope: unusable or unsupported override scopes discard the whole override with its original index, while invalid top-level file scopes fail without writing. Rule scaffolding rejects reserved diagnostic ids, Rust keywords, and template-name collisions before writing files, and creates separate positive and negative projects for cross-file rules.
