Capture bounded package metadata for dependency-section, package-name and secure-URL checks, refreshing diagnostics after saved manifest changes. Malformed, unreadable and oversized manifests produce shared discovery warnings whichever rules are enabled, including manifest-only projects. The migrated YAML-dependent checks skip the affected package while unrelated rules continue. UTF-8 BOM-prefixed manifests now supply parsed metadata and package identity without a false malformed warning, so YAML and own-package rules can report diagnostics previously skipped. A leading BOM also no longer hides a recoverable name in a malformed manifest. Import boundaries otherwise preserve existing fallback-identity behavior: malformed manifests with a recoverable name still support own-package path matching; unreadable manifests have no name, so only raw-URI and relative-path matching remain available. Asset checks still use their separate bounded manifest loader and filesystem facts. Manifests over 4 GiB previously rejected project analysis; oversized manifests now warn and skip optional metadata instead.
